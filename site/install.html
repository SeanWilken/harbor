install

Quickstart

Three roles: one hub, an agent on every machine, and the tray on desktops. All traffic stays on your Tailscale tailnet, and agents only connect out. There are no release binaries yet: you build from a checkout.

machineneeds
hub.NET 10 SDK, bun, podman, git, Tailscale (Linux; systemd user services)
agentgit and Tailscale; the agent is one self-contained file (about 22 MB)
build machine.NET 10 SDK, to publish agents for other platforms

01
Hub

git clone https://github.com/SeanWilken/harbor && cd harbor
cp harbor.example.json harbor.json   # set hub.admins, roots, services
deploy/install-pg.sh                 # once: PostgreSQL 18 in a podman quadlet
deploy/install-hub.sh                # hub + its own agent as a user service, tray at login

install-hub.sh builds the UI and the hub, installs them under ~/.local/share/harbor, copies your config to ~/.config/harbor/hub.json (mode 600) and enables harbor-hub. Re-run it to update. The UI is at http://127.0.0.1:7420 and at the hub's tailnet name on the same port.

  • loginctl enable-linger "$USER" keeps the hub running while you're logged out.
  • HTTPS for phones and tablets (needed for a secure context): set hub.serveListen to http://127.0.0.1:7425, then sudo tailscale serve --bg --https=7443 http://127.0.0.1:7425.

Never point Tailscale Serve or any proxy at port 7420: loopback there is trusted as admin.

02
Pair a machine

On the hub: tray → Pair a device…, or the web UI → Pending → pair a device. You get a one-time code (ten minutes, one use) and the hub address agents should use. Without a code, a new machine waits as pending until you approve it.

03
Windows: tray and agent

winget install Microsoft.DotNet.SDK.10 Git.Git
# from a checkout, Tailscale logged in to the same tailnet
powershell -ExecutionPolicy Bypass -File deploy\install-windows.ps1 -Hub http://<hub>:7420 -Code ABCD-EFGH

Builds harbor-agent.exe and harbor-tray.exe into %LOCALAPPDATA%\harbor\bin, writes a config with whichever source folders exist (or pass -Roots), adds a Startup shortcut and starts the tray. The tray runs the agent hidden and restarts it if it exits. When the hub knows newer harbor commits, the tray offers Update harbor….

04
Linux and Raspberry Pi: agent

dotnet publish src/Harbor.Agent -c Release -r linux-arm64 -o out   # linux-x64 for PCs
scp out/harbor-agent pi:~/.local/bin/
# on the machine
harbor-agent pair ABCD-EFGH --hub http://<hub>:7420 --config ~/.config/harbor/harbor.json

Edit roots in that config, install deploy/harbor-agent.service (a systemd user unit; steps inside) and loginctl enable-linger "$USER" on a headless machine. On a Linux desktop, add the tray with deploy/harbor-tray.desktop.

05
Check it

harbor-agent status     # tethered (exit 0), waiting (1), not (2)
harbor-agent snapshot   # what it would send, no hub needed
harbor-agent manifest   # OS, packages and repo locations

Configuration

Every field is optional; harbor.example.json documents them. The ones you'll touch:

fieldmeaning
machinename on the hub (default: hostname)
roots, ignore, maxDepthwhere to look for repos and what to skip
serviceschecks: systemd, systemdUser, process, port, http, podman
agent.hubthe hub's tailnet address, never loopback
agent.allowjob kinds this machine will run (default ["fetch"])
hub.admins / hub.viewersTailscale logins; "*" as a viewer means anyone identified on the tailnet
hub.recapweekday and the behind / dirty / neglected thresholds in days

More detail lives in the repository: docs/INSTALL.md, README.md and docs/OVERVIEW.md.
